# VectorDrive 2808 · 矢驱 2808

面向 2808 电机的紧凑型 FOC 驱动板项目。本页按硬件资料、个人贡献和测试证据整理，供电机驱动与机器人嵌入式岗位的项目交流使用。

原仓库说明将电流环与速度环列为支持功能；目前公开资料以硬件源文件为主，尚无配套固件与实测记录可供复核，因此这里不将功能描述视为测试通过的结论。

## 个人贡献

参考遥想星空的设计，完成原理图调整、PCB 大范围重新布局及部分芯片替换，并完成固件与板卡焊接。具体改动与测试材料如下。

- **固件：**［代码来源、本人实现或修改、仓库链接与对应提交］

### 主要硬件改动

- **5 V 电源：**将原 LDO 方案替换为 `MP2359`（U5）Buck；3.3 V 供电仍采用 `SPX3819-3.3` LDO。设计目标是提高转换效率、降低损耗与发热。效率和温升对比数据待补，暂不声明已验证的改善幅度。
- **低侧电流采样：**采用 `INA181A2IDBVT`（U6、U8）放大 U/W 两路低侧电流信号，对应分流电阻为 10 mΩ，参考电压为 1.65 V。以上依据工程文件静态核对；采样量程、校准结果、PWM 同步及控制中的实际使用方式待补。
- **PCB 层叠：**改为四层板，增加参考平面并调整层叠。各层用途、参考关系及相邻层安排待补；串扰、EMI 或其他性能收益尚未提供验证数据。
