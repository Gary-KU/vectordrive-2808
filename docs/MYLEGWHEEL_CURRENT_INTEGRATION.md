# MyLegwheel 六路电流 FOC 接入

硬件分配按用户 2026-11-01 确认，MyLegwheel 默认选择六路 A1 电流后端。

| 位置 | 节点 ID | F103 固件 | 极对数 | Kt（Nm / 本固件 Iq A） |
|---|---|---|---|---|
| 左轮 | 3 | `gimbal_foc_2808.hex` | 7 | 约 0.06616，KV 初估，未实测确认 |
| 右轮 | 7 | `gimbal_foc_2808.hex` | 7 | 同左轮，分别验证安装方向 |
| 四关节 | 1、2、5、6 | `gimbal_foc_4015.hex` | 11 | 0.23，用户提供 |

主控工程：`D:/CODE/FOC_WHEEL/foc-wheel-legged-robot-master/damiao/MyLegwheel`。配置入口为 `App/Services/Inc/motor_foc_config.h`，协议/会话为 `App/Services/Src/motor_foc.c`，诊断与维护接口声明见 `motor_foc.h`。主控侧完整操作说明在该工程 `docs` 中。

本次改变的是控制输出链路：LQR/VMC 的 Nm → 轴端传动比 → `Iq = Nm / Kt` → 方向映射一次 → 实际读回的电流限幅。A1 电流节点绕过原来的 Nm/V 经验系数和反电动势电压补偿。旧电压后端保留为显式 `legacy-voltage` 构建，不会与 A1 同槽输出。

2808 参数来自用户：KV=125 rpm/V、线电阻9 Ω、相电阻4.5 Ω、线电感3.4 mH、标称最大电流3.3 A、最大力矩0.1 Nm。本库 Clarke/Park 使用相电流峰值对应的 Iq；按常见 FOC 约定以 `8.27 / KV` 得到约0.06616 Nm/A，仅作为初估，不自动设为实测确认值。参考 [ODrive 的 Iq 与 torque_constant 定义](https://docs.odriverobotics.com/v/latest/fibre_types/com_odriverobotics_ODrive.html)。最大力矩和最大电流不一定来自同一工作点，不能直接用两者之比当已标定 Kt。R/L/KV 仅记录为电机元信息，不自动重整 PI 或提高电流上限。

当前H723本地电流限幅仍为±1 A，F103上电默认也为1 A；2808 与 4015 均允许停机设置请求上限3.3 A（4015原先的1 A上限已取消），矢量限压5 V与独立相过流保护1.5 A保持。该请求范围不提高整车主控本地限流，也不等于实测3.3 A输出。4015 名义力矩限幅约 ±0.23 Nm；2808 按估算约 ±0.066 Nm。实际可达力矩还受母线电压、绕组压降、转速、电流动态和热条件限制。电机“最大3.3 A”不能直接代替本驱动板的软件和硬件限值。

接入顺序：

1. 逐块烧录对应型号 F103 固件，保留 ID 区；上电停机。一次只接一块板，用上位机参数页“板上节点 ID · 掉电保存”分配表中 ID。顶部“连接 ID”只选择地址。
2. 逐节点在装车前、空载且机械安全时确认方向并完成对齐，然后用上位机“保存当前有效零点并重启”写入 Flash、读回确认。设置 ID 会重启并重采偏置；已有匹配校准时会静默恢复，不再吸合。六块板全部确认保存后再装入带负载结构。
3. PC 调参时让机器人主控停止输出。交给 H723 前，PC 上位机先停止并断开；H723 自己完成新的 STOP 握手和参数3/4/5实际读回。两个主机同时向同一节点持续发目标会争用序号与控制意图。
4. 在 H723 的 `g_motor_foc.calibration[ID-1]` 核对 Kt、安装方向、传动比相关配置、动态响应确认。固件 `dir` 用于电气角校准；H723 的安装方向用于机身坐标，分别验证。
5. 四关节另需确认单圈角的机械分支/零位 `angle_anchor_rad`、`angle_anchor_confirmed` 和 `joint_timing_confirmed`。快速反馈仍为异步采样，5 ms 原始接收配对和新鲜度门禁保留；超期会拒绝控制。
6. 先使用明确限时的直接 mA 调试，再确认整车 Nm/LQR。电流斜坡默认1 A/s，从0到1 A约1 s，与原电压模型的响应不同；主控读取实际斜坡并要求动态响应确认，不能直接沿用原增益就宣称平衡稳定。

直接电流调试不依赖 Kt：在所有整车输出停止、固件校准/反馈有效后，设置 `g_motor_foc.debug_current_ma[ID-1]` 和 `debug_duration_ms[ID-1]`，最后置 `debug_request_mask` 对应位。接口限制绝对值≤200 mA、时长≤1000 ms；过期停止，新请求不能在运动中排队。它只验证电流执行链，不证明整车力矩模型或负载性能。

总线1 Mbps，电流目标每节点100 Hz、新序号并等待执行 ACK；FAST机械角/速度/Iq目标200 Hz，状态和诊断100 Hz。软件退出CURRENT、反馈/ACK过期、bus-off、TX过期或参数会话失效都会撤销控制意图；通信恢复后维持停机，不自动清故障、对齐或续发旧电流。主控与驱动板均采用硬件仲裁重发和有界旧帧取消。

本轮完成代码、协议与离线构建回归；没有执行六电机实机联动或平衡测试。六路多节点实际 FIFO 丢帧、角度时序、力矩标定和负载动态仍应按上述步骤验证。
