# 板端请求上限与相电流保护（2808 / 4015）

2808/7极对与4015/11极对固件现在都允许参数3（`iq_limit`）在0.01..3.3 A范围内设置（4015原先的0.01..1 A上限已取消）。上电默认均为1 A，默认停机。两种固件的CAN IQ报文范围均为±3300 mA，超过当前参数3仍返回RANGE。上位机须收到执行ACK与相同序号的真实参数读回，才认可参数设置成功；主机输入范围为±3.3 A，若已真实读回参数3，则目标超过该读回值时弹出“目标超过已读回的电流限幅 ±N A”并拒绝本次发送；未读回参数3时不拦截，仍由板端执行ACK与RANGE决定。

请求上限与相电流保护独立：2808 固件的固定相过流阈值为2.0 A，4015 保持1.5 A；U/W实测和重建V相的保护判断保持。ADC触轨、编码器、驱动故障、CAN时效和STOP握手保护保持。电压矢量限压5 V、PWM窗口8%..82%、电流斜坡1 A/s也保持。设置3.3 A不会隐式提高保护阈值，也不会隐藏截断请求；2808 任一实测或重建相电流超过2.0 A即故障停机。

`LIMITS_READ=0x14`是只读查询。命令ID为`0x200+node`，8字节`A1 14 seq 00 00 00 00 00`；执行ACK为`0x380+node`。保护信息回复ID为`0x600+node`：

| 字节 | 含义 |
|---|---|
| 0 | A1 |
| 1 | 14（回显opcode） |
| 2 | sequence |
| 3 | result |
| 4..5 | 型号请求上限，uint16小端，mA |
| 6..7 | 固定相过流阈值，uint16小端，mA |

2808 固件正常回复的末4字节为`E4 0C D0 07`（3300、2000），即请求上限3.3 A、相过流2.0 A；4015 为`E4 0C DC 05`（3300、1500）。该回复描述固件能力与保护，不替代参数3实际读回，也不授予运动权限。上位机完整读取9项参数后追加查询，也可通过终端`limits`或Controller.read_limits()单独查询。旧固件不支持时显示未知，保留原有STOP与参数通信。

使用顺序：连接并完成STOP握手，读取板上参数；2808 上电默认参数3为3.3 A，应显示“板端目标上限±3.3 A / 相电流保护2 A”。4015 上电默认参数3仍为1 A。普通参数只存在RAM；节点ID的Flash存储不受影响。烧录后方向、电气零点需要重新确认；本轮验证只在停机状态读取参数，不自动对齐或发运动指令。

实际电流能力仍受硬件与电机参数约束。按用户提供的2808相电阻4.5 Ω，零速1 A需约4.5 V，3.3 A需约14.85 V相电压；现有14 V母线与采样窗口下可用矢量约5.98 V，当前软件限5 V。3.3 A是允许的请求值，不是已验证的连续或峰值输出额定值。驱动器和采样量程需要另行匹配，不能通过提高本版本保护阈值来兑现3.3 A输出。

用于轮足机器人时，原MyLegwheel模型为整机1.45 kg、轮直径52 mm，尚需核对是否对应新实物。每轮理想切向力为`F=T/r`；用户提供的0.1 N·m最大力矩在半径5 cm时对应2 N/轮，未扣损耗且不代表连续额定。当前1 A/s斜坡影响快速平衡恢复，力矩常数、机械几何、负载动态和控制增益都需实测确认。
